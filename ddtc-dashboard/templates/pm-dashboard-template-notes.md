# PM Dashboard Template Notes

Create one Google Sheets workbook template named `DDTC Dashboard - Codex - PM Dashboard Template` with these tabs:

1. `Consolidated Dealer Profiles & Activity`
2. `Meeting Schedule Overview`
3. `IDA Data`
4. `Sync Log`

## Consolidated Dealer Profiles & Activity

- Reserve top rows for summary cards: total dealers, active DDCs, total meetings, and average Mystery Shop score.
- Start the raw data table below the summary area.
- Include filter views for region, DDC, and DPG.

## Meeting Schedule Overview

- Reserve top rows for this week, completed, upcoming, and overdue stats.
- Add chronological meeting tables with days-until countdown columns.

## IDA Data

- Add consolidated Pre-Assessment and In-Store Assessment columns.
- Add completion-status columns.
- Reserve a rollup area for network-wide training needs.

## Sync Log

- Add columns for timestamp, run ID, status, processed count, error count, duration, cursor, and message.
